🐳 Docker Cheatsheet

🔍 Informazioni e stato di Docker

  • docker --version – Mostra la versione del client Docker installato.
  • docker version – Mostra la versione del client e del server Docker.
  • docker info – Fornisce informazioni generali sul sistema Docker.

📦 Container

  • docker ps – Elenca i container attualmente in esecuzione.
  • docker ps -a – Elenca tutti i container, inclusi quelli fermi.
  • docker run <image> – Crea ed esegue un nuovo container da un’immagine.
  • docker run -it pippo2 sh – Avvia il container pippo2 con shell interattiva.
  • docker run -d --name <nome> <image> – Avvia un container in background con nome.
  • docker start <container> – Avvia un container fermo.
  • docker stop <container> – Arresta un container in esecuzione.
  • docker restart <container> – Riavvia un container.
  • docker rm <container> – Elimina un container.
  • docker logs <container> – Mostra i log del container.

🧠 Ispezione e monitoraggio

  • docker inspect <container|image> – Mostra i dettagli completi in formato JSON.
  • docker stats – Mostra l’uso delle risorse in tempo reale.

🖥️ Esecuzione comandi nei container

  • docker exec -it <container> bash – Apre una shell interattiva nel container.
  • docker exec <container> <comando> – Esegue un comando nel container.
  • docker exec pippo2 sh -c 'echo "Hello" > /data/paragraph.txt' – Scrive un file nel container.

💾 Volumi Docker

  • docker volume ls – Elenca i volumi Docker.
  • docker volume create <volume> – Crea un nuovo volume.
  • docker volume --help – Mostra l’aiuto per i comandi sui volumi.
  • docker run -v pippo-dati:/data alpine sh -c 'echo "Hello" > /data/hello.txt' – Scrive un file in un volume.
  • docker run --rm -v pippo-dati:/data alpine cat /data/hello.txt – Legge un file da un volume.
  • docker run --rm -v pippo-dati:/data alpine more /data/hello.txt – Visualizza il contenuto di un file.
  • docker run --rm -v pippo-dati:/data alpine ls -l /data – Elenca i file nel volume.

🌐 Network Docker

  • docker network ls – Elenca le reti Docker.
  • docker network create <network> – Crea una nuova rete.
  • docker network connect <network> <container> – Collega un container a una rete.
  • docker network inspect <network> – Mostra i dettagli di una rete.

🐳 Immagini Docker

  • docker images – Elenca le immagini locali.
  • docker pull <image> – Scarica un’immagine dal registry.
  • docker build -t <nome>:<tag> . – Crea un’immagine da un Dockerfile.
  • docker rmi <image> – Elimina un’immagine Docker.

🧩 Docker Compose

  • docker compose up -d – Avvia i servizi definiti in docker-compose.yml.
  • docker compose down – Ferma e rimuove i servizi.

🐝 Docker Swarm e servizi

  • docker swarm init – Inizializza Docker Swarm.
  • docker node ls – Elenca i nodi del cluster.
  • docker service create --name <nome> --replicas N -p host:container <image> – Crea un servizio Swarm.
  • docker service scale <servizio>=N – Modifica il numero di repliche.
  • docker service ls – Elenca i servizi Swarm.
  • docker service ps <servizio> – Mostra i task del servizio.
  • docker service update --image <image> <servizio> – Aggiorna l’immagine del servizio.
  • docker service rollback <servizio> – Ripristina la versione precedente.
  • docker service inspect <servizio> – Mostra i dettagli del servizio.
  • docker service rm <servizio> – Rimuove un servizio.
